
## Overview of the Project
I worked on the **Bento Grid** challenge from Frontend Mentor. Completing this project gave me great hands-on experience working with the grid system in the **Bootstrap** framework.

## My Approach and Customizations
I used the grid system in Bootstrap to create grid sections and cards of different sizes. Although Bootstrap provides many built-in styles and makes handling different screen sizes very convenient, configuring a complex, asymmetric grid layout can be a bit tricky.

To structure the webpage cleanly, I divided the overall layout into Bootstrap grids based on the design requirements and used Flexbox inside the individual grid items to handle internal alignment.

Used custom styles for the text color and background.

## Challenges Faced and How They Were Addressed
* **Grid Alignment:** Handling the grid in Bootstrap was definitely the biggest challenge during implementation, with aligning uneven grid sections being the most difficult part.
* **How It Was Addressed:** With the help of online video tutorials and W3Schools resource, I was able to troubleshoot the nested grid structure and achieve the final layout.

## Future Improvements
If given more time, I would focus on getting more practice with complex grid layouts to handle alignment faster and more efficiently.
